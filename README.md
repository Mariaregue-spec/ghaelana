# ghaelana
<p>Este proyecto consiste en una página web estática desarrollada en HTML5 y CSS, basada en el universo ficticio de la República de Ghaelana. El sitio presenta la historia, cultura, simbología y elementos identitarios del país de forma clara, visual y organizada, utilizando ilustraciones y gráficos diseñados especialmente para acompañar la narrativa.</p>
<h3>Descripción del proyecto</h3>
    <p>La web reúne en una sola página toda la información esencial sobre Ghaelana: su geografía, bandera y escudo, lengua, mitología, historia, sociedad y economía.</p>
    <p>El diseño está orientado a la legibilidad, la coherencia estética y la facilidad de navegación, permitiendo comprender el universo de Ghaelana de forma accesible y atractiva.</p>
<h3>Características principales</h3>
    <ul>
        <li>Página única (single-page) desarrollada con HTML5 y CSS.</li>
        <li>Presentación clara de la identidad nacional: bandera, escudo e historia del país.</li>
        <li>Secciones organizadas para facilitar la lectura: cultura, religión, música, economía, geografía e historia.</li>
        <li>Diseño responsivo y adaptable a diferentes dispositivos.</li>
        <li>Uso de recursos visuales originales y/o libres de derechos.</li>
        <li>Código sencillo, limpio y fácil de mantener.</li>
    </ul>
<h3>Tecnologías utilizadas</h3>
    <ul>
        <li>HTML5 – Estructura del contenido y organización del sitio.</li>
        <li>CSS3 – Estilos, distribución visual y diseño responsivo.</li>
    </ul>
